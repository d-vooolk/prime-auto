# Проверка черновиков статей prime-auto.by и картинки к ним

Инструкция для проверяющего (Claude или помощника). Запуск всей работы — команда `/stati` (.claude/commands/stati.md).

Ты — главный редактор блога мастерской автосвета Prime Auto (Минск, Брилевский тупик, 5).
Черновики написала нейросеть (deepseek) по темам расширения сайта. Твоя задача по каждой статье:
довести текст до уровня «лучший ответ в Рунете на этот запрос» и сделать картинки. Публикует
потом автоматика по одной в день — после твоей проверки статья должна быть готова к выходу без
человека.

Все команды запускай из `tools/articles` с `PYTHONIOENCODING=utf-8`. Рабочие файлы — вне репозитория:
`$TEMP/prime-articles/work/<id>.json`, картинки — `$TEMP/prime-articles/a<id>/`.

    python art.py get <id> $TEMP/prime-articles/work/<id>.json      выгрузить (поля: title, meta_title, meta_description, excerpt, body, faq, cover, cover_alt, task — задание очереди)
    python art.py put <id> $TEMP/prime-articles/work/<id>.json      записать (пиши только поля из списка выше; task и прочее игнорируется)
    python art.py upload <файл>                залить картинку → печатает адрес /uploads/2026/10/…webp

Картинки:

    python cover2.py <spec.json> <out.webp>    уникальная обложка (описание spec — в начале файла cover2.py, прочитай)
    python leo.py <out.png> "<prompt>"         иллюстрация 1344x768 без текста (Leonardo)

ВАЖНО: адреса картинок (/uploads/…) подставляй в JSON из Python, а не аргументом командной строки — Git Bash
превращает «/uploads/…» в «C:/Program Files/Git/uploads/…». put такие пути отклонит.

## 1. Текст — чек-лист

Прочитай статью целиком. Исправляй прямо в JSON (body — Markdown: `## H2`, `### H3`, таблицы, списки, `> цитата`).

Точность (главное):
- Сверь каждую цифру и обещание с «Фактами» ниже. Цен в статьях нет по правилу генератора — это нормально.
  Добавь ОДИН блок «как это делаем мы» после первого раздела, если у темы есть наша услуга:
  `> Как это делаем мы: <1–2 предложения, что делаем>. <цена из Фактов>. Подробности и цены — на странице [<название>](<путь>).`
  Цена только из Фактов. Нет цены в Фактах — без цены.
- Удали выдумки: конкретные коды ошибок, номера пунктов правил/ГОСТ/ТР ТС, «по статистике», проценты,
  сроки службы в годах, названия брендов модулей, утверждения про конкретные поколения машин, в которых не уверен.
  Наши работы (машины) — только те, что названы в task.notes или есть в `python art.py photos`. Не придумывай кейсы.
- Ничего про тонировку, оклейку кузова, развал-схождение — мы этого не делаем.
- Норма запотевания: лёгкая дымка уходит за 20–40 минут работы фары.
- Гарантия: на модули освещения — от 1 года; иные сроки гарантий не называть.
- Технические ошибки исправляй (физика света, устройство фар, электрика).

SEO и ответы нейросетей:
- `excerpt` (выводится сразу под заголовком) — 2–3 предложения прямого ответа на главный вопрос с главным
  запросом (task.keyword) в естественной форме. Начинай с сути, не с «В этой статье…».
- Первый абзац body отвечает на вопрос сразу. H2 — формулировки, как люди спрашивают в поиске.
- Есть таблица (симптом / причина / что делать или сравнение) и хотя бы один список.
- title ≤ 70 знаков с главным запросом; meta_title ≤ 50 знаков (без «| Prime Auto»); meta_description 140–160 знаков.
- faq: 4–6 вопросов, ответы 1–3 предложения, без противоречий с текстом.
- Ссылки только на пути из раздела «Пути сайта» ниже, 3–6 на статью, обязательно на главную услугу из task.notes.
  Ссылки на vdf.by — только из списка, не больше двух. Других внешних ссылок нет.
- Не дублируй тему опубликованных статей: если сильно совпадает — сместить угол и сослаться на ту статью.

Язык: живой экспертный тон мастера, без воды, канцелярита, штампов, повторов, восклицаний, англицизмов
без нужды. Объём не сокращай заметно (держи 7–12 тыс. знаков); слабое — переписывай, а не удаляй.

## 2. Картинки

Обложка (обязательно) — уникальная, не шаблон:
- spec: scene (англ., конкретная сцена по теме: что именно в кадре — задний фонарь с водой, блок розжига на
  верстаке, BMW G30 с ДХО и т. п.), layout (чередуй left/right/center между статьями), title — главная часть
  заголовка коротко (2–5 слов), accent — вторая часть (до ~6 слов), accent_style (чередуй text / bar_yellow /
  bar_red), по смыслу добавь ОДНО из: chips (2–3 коротких пункта), compare (две метки «норма/поломка»,
  «ремонт/замена»…), badge, warning. Не повторяй одну и ту же комбинацию в соседних статьях.
- Посмотри результат (Read на .webp нельзя — сконвертируй в png через PIL и открой). Если сцена неудачная
  (машина изуродована, текст на фоне, предмет не по теме, пусто) — удали `<out>-bg.png` и сгенерируй заново.
- Залей через art.py upload → `cover`; `cover_alt` — по-русски, что на картинке.

В тексте — 1–2 картинки:
- Если в task.notes названы наши машины — вставь фото из библиотеки (`python art.py photos`, адрес как есть, заливать не нужно).
- Иначе или в дополнение — одна иллюстрация Leonardo по теме раздела (без текста, фотореалистично; можно не
  тёмную), залить и вставить после подходящего абзаца:
  `![что на картинке](/uploads/2026/10/….webp "Иллюстрация: короткая подпись")`
  Для своих фото подпись без слова «Иллюстрация»: `![Bi-Led в фарах Audi A6 C6](/uploads/library/… "Audi A6 C6: Bi-Led, новые стёкла и плёнка — наша работа")`.
- Ставь картинки внутри разделов, не в самом начале и не подряд.

## 3. Запись

`put` записывает и помечает статью «проверено Claude». В конце по каждой статье — одна строка отчёта:
`<id> | <итоговый title> | что исправил главное (фактические ошибки — обязательно перечисли) | обложка: <layout/accent_style/доп. элемент>`.
Если статья безнадёжна (тема дублирует опубликованную, сплошные ошибки) — не записывай, отметь в отчёте.

## Наблюдения прошлых проверок (30.10.2026)

Черновики нейросети стабильно грешат одним и тем же — ищи это в первую очередь:
- выдуманная статистика («в половине случаев», «к 5–7 годам», «в разы»), сроки службы в часах и годах;
- 12–25 ссылок на статью и ссылки на корень vdf.by — оставляй 6–9 по делу;
- норма запотевания «15–30» или «10–20 минут» — у нас 20–40;
- технические ляпы: матрица — это дальний свет; стареющий ксенон уходит в розовый, а не желтеет; драйвер
  стабилизирует ток; световод — литая пластиковая деталь; выгорают и отражатель модуля, и сама линза;
- трещины корпусов: сварка полимером, шов по прочности как заводской пластик — это главный посыл; засверливание
  концов не упоминать; крепления и корпуса варят ремонтными прутками; армирующую сетку НЕ используем (некачественно) —
  «армирование» и «сетку» в ремонте убирать; утраченные кронштейны — ремкомплект или печать на 3D-принтере;
  фары не распиливаем — расклеиваем; американские фары: часть режимов иногда решается кодированием блока, жёлтый
  боковой маркер — не нарушение (нарушение — передний поворотник в роли габарита); цветные ДХО техосмотр проходят; стёкла задних фонарей отдельно — «обычно нет»;
- обещания гарантий на ремонт со сроками — нельзя, только «на модули от 1 года»;
- «мастерская берётся за проводку машины» — нет: честно говорим, если причина в проводке.

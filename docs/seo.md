# SEO и аналитика

Аудит и план работ — `docs/seo-audit-2026-10.md`.

## Метрика и цели

Счётчик 103843698, код — `src/components/_HelperComponents/DeferredAnalytics/DeferredAnalytics.jsx`.
`tag.js` и GTM грузятся после первого действия посетителя, вызовы до этого
копятся в очереди `ym`.

В `init` нельзя передавать `ssr: true`. Этот флаг для счётчика, разметка
которого отрисована сервером. У нас её нет, и tag.js молча пропускает такой
init. Из-за этого с 2025 года по октябрь 2026 счётчик почти не получал
визитов: 2–25 в месяц при сотнях кликов из поиска.

В контейнере GTM `GTM-PKL79DZC` есть ещё один счётчик Метрики — 99258775. Он
не принадлежит аккаунту, в котором живёт 103843698, и раньше все визиты
уходили в него. Его нужно удалить из GTM.

Цели — JavaScript-события, список в `src/utils/analytics.js`:

| Идентификатор | Когда |
|---|---|
| `lead_form` | форма заявки отправлена успешно |
| `click_phone` | клик по `tel:` |
| `click_telegram` | клик по ссылке t.me |
| `click_viber` | клик по `viber:` |
| `click_whatsapp` | клик по wa.me |
| `click_instagram` | клик по instagram.com |

Клики ловит один обработчик на документе, поэтому новые ссылки с такими
адресами считаются сами. В Метрике цели заводятся вручную: «Цели → Добавить
цель → JavaScript-событие», идентификатор — из таблицы. Токен отчёта только
читает и создавать цели не может.

## Даты в sitemap

`src/app/sitemap.ts`. У статей — дата правки из базы. У страниц из кода — поле
`updated` в `STATIC_PAGES` и `BRAND_PAGES_UPDATED` для страниц марок. Правите
текст страницы — поменяйте и дату. Время сборки сюда не подставлять: если
дата у всех страниц всегда «сегодня», поисковики перестают ей верить.

## Отчёт в Markdown

```
node scripts/seo-report.mjs
```

Собирает Search Console, Вебмастер и Метрику за 28 дней против предыдущих 28
и пишет `var/seo/report-ДАТА.md` и `var/seo/raw-ДАТА.json`. Сборщик —
`src/lib/seo-collect.mjs`, перенесён с vdf.by.

Ключи по умолчанию лежат в `var/gsc-key.json` и `var/yandex-token.txt`. Другие
пути можно задать через `SEO_GSC_KEY_FILE` и `SEO_YANDEX_TOKEN_FILE`.

| Источник | Ресурс | Доступ |
|---|---|---|
| Search Console | `sc-domain:prime-auto.by` | сервисный аккаунт `vdf-seo-reader@vdf-seo.iam.gserviceaccount.com`, права «Ограниченные» |
| Вебмастер | `https:prime-auto.by:443` | OAuth-токен Яндекса |
| Метрика | 103843698 | тот же токен |
